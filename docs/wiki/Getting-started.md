# Getting started

Choose the Windows, Apple Silicon Mac, Intel Mac or Ubuntu x64 download on [[Installation]]. Each includes the scientific runtime and offline help. Windows is unsigned; Mac packages are ad-hoc signed without Apple Developer ID signing or notarization. Release checksums accompany the downloads.

The initial barnase–barstar example opens locally. Choose Molecule for coordinates or New construct project for sequence-only work. Open project restores embedded data; Recent projects shows local previews and Recover autosave opens a recovered copy.

Drag to orbit, wheel to zoom and right-drag to pan. Arrow keys rotate, Shift+arrows pan, +/− zoom and F fits. Cmd+K / Cmd+S on Mac, or Ctrl+K / Ctrl+S elsewhere, open Commands and save. Text fields retain normal editing shortcuts. Settings provides Midnight, Liquid Glass and Painted Pixels, standard typography, contrast/transparency controls and layout presets.

Core work is offline. Reference retrieval and published-version checking happen only when explicitly selected. Read [[Construct-and-maturation]], [[Molecular-inspection]] and [[Projects-and-scientific-interpretation]] before interpreting derived results.
