# Proteonator 1.2

Proteonator now connects precursor/construct sequences, declared maturation chemistry, coding RNA/DNA and supplied molecular structures in one local workspace. The release includes the emerald fedora identity, richer selection/scenario/comparison tools, RNA secondary structure, registered coordinate frames, scientific figures/review bundles and more resilient projects/recovery.

## Highlights

- FASTA/GenBank/CDS, exact sourced modules, virtual cleavage/trimming, glycine-donor amidation, desired disulfides, neutral masses and evidence by state.
- Reproducible coding segments, actual source codon links, reviewed sequence/structure substitutions and local ViennaRNA secondary structure/probabilities.
- Canonical residue substitutions, supported primary amides, compatible explicit disulfides and trans-4-hydroxyproline with bounded chemistry checks.
- Full contact tables/CSV, typed geometric interactions, editable measurements/maps, reviewed fit/evaluation regions, confidence/feature evidence and source diagnostics.
- Actual topology-registered frames, unaligned RMSD/RMSF, transparent PNG, SVG diagrams/profiles, HTML/JSON/CSV, checksummed review ZIP, saved-view storyboard and camera-presentation WebM.
- Preserved assembly branches and per-scenario history, transactional rollback, compressed projects, two recovery generations, local recent previews and incremental appearance updates.

## Important corrections and limits

Explicit covalent/disulfide transfer now handles differing author/label chain identifiers during OpenMM preparation. Recalculate earlier local-response results affected by that condition. Failed/cancelled operations and corrupt preferences/recovery retain the previous valid state; autosave waits for atomic operations to finish.

Local minimization is not a global-fold, expression-yield or binding-affinity predictor. Coding segments are not recovered native transcripts. RNA-family evidence imports are supported; native Infernal/tRNAscan-SE engines/databases are not bundled. Imported frames and camera presentations have distinct meanings.

The native release is Windows 11 x64. The installer is unsigned because no publisher credential is available. Other native platforms have not passed distribution/runtime checks. Full source, third-party notices and scientific limitations accompany the application. See the [user guide](USER_GUIDE.md), [methods](SCIENCE.md) and [roadmap](../ROADMAP.md).
