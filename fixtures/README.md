# Example structures and scientific fixtures

Bundled archive structures are public wwPDB/RCSB coordinates: 1BRS (barnase–barstar), 1CRN (crambin), 1UBQ (ubiquitin), 4HHB (hemoglobin and heme), 1BNA (DNA), and 1HZH (antibody with glycans). Their entry records identify original depositors and primary publications. Exact bytes, source URLs and SHA-256 values are in PROVENANCE.json. Archive data use CC0; scientific credit remains with their depositors.

The synthetic directory contains explicitly artificial analytic/alignment/load fixtures. The translated crambin grid and perturbed comparison are not observed biological assemblies or PTM-induced conformations. Expected geometry files and the independent reference script support reproducible numerical checks. Chemistry definitions used by the current application are the separately versioned wwPDB CCD files under data/components.
