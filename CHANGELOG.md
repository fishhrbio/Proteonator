# Changelog

## 1.2.1

- Added separate macOS disk images for Apple Silicon and Intel, with native scientific runtimes, fedora icons, document associations and Mac menu/keyboard conventions.
- Added an Ubuntu x64 Debian package with native scientific libraries, an applications-menu entry, project association and sandbox-preserving installation.
- Made project arguments, file URLs, runtime discovery and third-party notice collection portable across Windows, macOS and Linux.
- Added native package installation, scientific/interaction checks, project/settings retention, reinstall and uninstall verification, with separate downloads and platform-specific guidance.
- macOS applications are ad-hoc signed, without Apple Developer ID signing or notarization. The Windows installer remains unsigned. Platform and scientific limitations remain explicit.

## 1.2.0

- Added a source-preserving construct/maturation workspace: FASTA/GenBank/CDS, modules, virtual processing, explicit mature chemistry, neutral masses, descriptive profiles, target requirements and state-specific evidence.
- Added reproducible coding RNA/DNA generation, versioned genetic codes, source codon links, reviewed structural mapping, local RNA secondary structure/probabilities and sequence-bound imported RNA-family evidence.
- Added canonical side-chain substitutions, supported primary terminal amides, compatible explicit disulfide links and trans-4-hydroxyproline, with bounded chemistry and parameter checks.
- Added range/set queries, adjustable neighborhoods, paged keyboard navigation, isolated selections and named views; retained scenario branches and per-scenario history across assembly changes.
- Added scenario folders/tags/pins, reviewed source-bound edit tables, full contact CSV/residue summaries, typed geometric interactions and filterable source diagnostics.
- Added reviewed alignment tables with component identities, separate fit/evaluation regions and explicit excluded/unpaired gaps in displacement exports; added state-bound confidence/validation imports and feature/domain tracks.
- Added editable measurements, per-map controls, actual registered trajectory/ensemble frames, unaligned frame statistics, scientific SVG/CSV, figure presets, review ZIPs, saved-view storyboards and camera-presentation WebM.
- Added recoverable compressed projects, two recovery generations, local recent previews, task history, command favorites/recents, layout presets, explicit version checking and the emerald fedora identity.
- Reduced unnecessary molecular reparsing for appearance changes and retained map resources; batched analytic measurements avoid repeated scientific-process launches.
- Fixed explicit disulfide/covalent link transfer when author and label chain IDs differ during OpenMM preparation. Earlier local-response results involving that condition should be recalculated.
- Fixed stale assembly edit displays, project/history restoration, failure rollback, autosave during partial edits, corrupt-recovery rotation, recent-index corruption and incompatible app-local C++ runtime selection.
- Fixed project-file opening from installation folders with spaces and Unicode, and cleared the owned default file association during uninstall.

Scientific limits remain explicit: local minimization is not global folding or affinity; coding segments are not recovered transcripts; RNA-family engines/databases are not bundled. Windows distribution is unsigned when a publisher credential is unavailable.

## 1.1.0 — Proteonator

- Renamed the application to Proteonator, with a new fedora-and-bill outline icon and consistent installer, guide and release naming.
- Added a common molecular workspace with native menus, command search, configurable toolbar/shortcuts, resizable/collapsible side panels, contextual selection and optional onboarding.
- Added Midnight, Liquid Glass and Painted Pixels skins, with shared functions and accessibility preferences.
- Adopted a bundled Mol* viewport for assemblies, mixed molecular components, component controls, surfaces, atom/residue inspection, measurements, maps and linked comparisons.
- Added seven supported PTM constructors, immutable source coordinates, reversible edits, branched scenarios and visible changed chemistry.
- Added contact, bond, angle, torsion, added-atom overlap and displacement comparisons, plus reviewed exact/sequence-assisted rigid alignment.
- Added a standalone CPU runtime for supported local minimization, separately prepared source controls, explicit calculation settings and convergence/provenance reporting.
- Added optional UniProt/SIFTS/Ensembl context, sequence-checked residue mapping, transcript/isoform/processing summaries and portable cached records.
- Added `.proteonator` projects with embedded maps, notes, selections, measurements and scene state, earlier-project import, mmCIF/JSON/captioned-PNG exports and updated offline help.

Local minimization has a bounded chemistry scope. Methyllysines support construction/geometry; their relaxation parameters are not bundled. Global folding, equilibrium sampling and quantitative binding-affinity prediction are outside 1.1's scientific scope.

## 1.0.0

Initial local protein viewer, residue annotations, interface geometry, reviewed Cα fitting, portable projects and exports. Earlier project files can be opened and saved as new Proteonator projects.
