# Corresponding upstream sources

The application redistributes unmodified libraries separately from its MIT original code. License notices are in this directory. These links identify corresponding source versions.

- [Gemmi v0.7.5](https://github.com/project-gemmi/gemmi/archive/refs/tags/v0.7.5.tar.gz), MPL-2.0.
- [OpenMM 8.6.0](https://github.com/openmm/openmm/archive/refs/tags/8.6.0.tar.gz), per-component terms in OpenMM-Licenses.txt. The wheel identifies internal revision c6173db6e8edd705eb59172bd21e9ce69c572405.
- [NumPy v2.3.5](https://github.com/numpy/numpy/archive/refs/tags/v2.3.5.tar.gz), BSD and bundled terms.
- [CPython v3.12.14](https://github.com/python/cpython/archive/refs/tags/v3.12.14.tar.gz), PSF and bundled terms.
- [Mol* v5.13.0](https://github.com/molstar/molstar/archive/refs/tags/v5.13.0.tar.gz), MIT.
- [Electron v45.3.0](https://github.com/electron/electron/archive/refs/tags/v45.3.0.tar.gz), MIT and runtime terms.
- [PyInstaller v6.17.0](https://github.com/pyinstaller/pyinstaller/archive/refs/tags/v6.17.0.tar.gz), GPL with application-distribution exception.

JavaScript dependency versions, repositories and full texts are in JavaScript-dependencies.json and JavaScript-dependencies.txt. The offline package retains dynamic runtime files rather than statically incorporating Gemmi into Proteonator's original source.
